# Homebrew Tap

Homebrew packages maintained by https://github.com/campfireshuffle.

## Vinny

Install Vinny with one fully qualified command. Homebrew trusts only this cask, not the entire third-party tap:

```sh
brew install --cask campfireshuffle/tap/vinny
```

## NocFree RMK Companion

Install the app for an Apple Silicon Mac:

```sh
brew install --cask campfireshuffle/tap/nocfree-rmk-companion
```

[See the app and its features](https://github.com/campfireshuffle/nocfree-and-rmk).
